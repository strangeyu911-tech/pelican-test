# 题名（主题词）设计原则

> 2026-10-28 用户给两张参考图之后定的。参考图本身**不入库**（是别人的画面截图），
> 这里只记抽象出来的原则 + 我们的落地方式。

## 原则

1. **每个时代的题名用那个时代的"写字方式"。** 不能 20 格共用一套现代三行排版 ——
   一部讲美术史的电影，题名本身就应该是美术史的一部分。
2. **位置必须变。** 竖排题跋在右上、皮影戏台口的木牌在左上、默片字幕卡在下方居中、
   App 的账号名在左下…… 观众第二次猜不到标题在哪，才会真的去看画面。
3. **题名要"属于"那一格的材料。** 岩画上的字是赭石颜料抹上去的，拓片上的字是刻出来的，
   示波器上的字是荧光余辉，8-bit 的字是像素点。**同一套字换颜色是不够的。**
4. **只借原则，不抄版面。** 参考图里的"黑底描金匾额""竖排加朱印"是中文书画题跋的
   公共传统（千年公有领域），可以用；但那两张图的**具体版面、装饰纹样、印章内容**不照搬。

## 八种样式（`src/kit/titles.js`）

| 样式 | 做法 | 用在哪 |
|---|---|---|
| `plate` | 现代三行 + 细线 | 万用兜底 |
| `vertical` | 竖排（毛笔楷书）+ 可选朱印 / 简牍框 / 石痕 | 唐、宋、汉、八大、浮世绘、清明上河图、埃及 |
| `plaque` | 描边框 + 双线 + 角饰 | 皮影、莫卧儿、玛雅 |
| `painted` | 颜料手写（双层偏移 + 粗糙下划） | 撒哈拉、星月夜、呐喊 |
| `caption` | 默片字幕卡（黑底白字 + 上下细线） | 诺斯费拉图 |
| `mono` | 等宽 + 前缀（`//` `>` `$`）+ 可选辉光 | 代码、示波器 |
| `hud` | UI 浮层（账号名 + 说明 + 投影） | 竖屏短视频、聊天 |
| `pixel` | 小尺寸烤图 + 关掉插值放大 | 8-bit |
